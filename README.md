# Happy Birthday, Mahi Didi

A personal birthday surprise made with love for Maya Tiwari (Mahi). This lightweight, responsive website brings together family photos, a heartfelt letter, a birthday countdown, music, and an interactive cake wish.

## Features

- Birthday countdown to **20 November 2026**
- Personal birthday letter
- Photo gallery featuring the images in `assets/`
- Birthday music player
- Interactive cake and wish button
- Responsive layout for desktop and mobile
- No build tools or package installation required

## Preview locally

1. Download or clone this project.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets/` folder together.
3. Open `index.html` in a web browser.

> The page uses relative paths for its styles, script, photos, and music. Keep the original folder structure so everything loads correctly.

## Publish and share

### Netlify Drop

1. Sign in at [Netlify](https://app.netlify.com/).
2. Open [Netlify Drop](https://app.netlify.com/drop).
3. Upload the project folder (or a ZIP containing its contents).
4. Share the public `https://...netlify.app` URL Netlify provides.

### GitHub Pages

1. Push the project files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch and the project root folder, then save.
5. Share the published URL shown in the Pages settings.

## Customize

- Update the birthday date in `script.js` if the celebration date changes.
- Edit the message and page content in `index.html`.
- Adjust colors, typography, and layout in `style.css`.
- Keep photo and music filenames in `assets/` consistent with their references in the page.
